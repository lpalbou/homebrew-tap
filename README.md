# Homebrew Tap

Homebrew formulae for [lpalbou](https://github.com/lpalbou)'s tools.

## Install

```bash
brew install lpalbou/tap/cursordump
```

| Formula | Description |
|---|---|
| [cursordump](https://github.com/lpalbou/CursorDump) | Explore Cursor agent sessions, export SFT/CPT datasets, full backups |
